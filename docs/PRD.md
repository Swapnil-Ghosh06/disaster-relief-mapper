## 1. Problem Statement

During floods, cyclones, and other natural disasters, affected communities struggle to locate nearby shelters, food banks, and medical camps due to fragmented and inaccessible information. Relief coordinators lack tools to visualize real-time resource availability or reroute aid when primary resources become inaccessible.

This project builds an interactive 3D disaster simulation platform that consolidates resource data, simulates disaster scenarios, and dynamically reroutes relief efforts to available resources.

---

## 2. Goals

### Primary Goals
- Visualize disaster-prone regions in 3D with resource locations marked
- Simulate flood and cyclone scenarios with realistic animations
- Dynamically mark resources as offline when affected by disaster
- Reroute affected populations to nearest available resources automatically

### Secondary Goals
- Provide parameter controls so users can adjust disaster severity
- Show real-time statistics (resources offline, estimated affected population)
- Support multiple Indian cities known for disaster vulnerability

## 5. Features

### F1 — 3D Map View
- Load OpenStreetMap base tiles in 3D perspective (45° pitch)
- Dark map style for emergency operations aesthetic
- Smooth zoom, pan, rotate controls
- Region selector: Chennai, Mumbai, Bhubaneswar, Kolkata

### F2 — Resource Layer
- Display shelters, food banks, medical camps as color-coded markers
- Click marker → popup with name, capacity, status, type
- Layer toggles to show/hide each resource type
- Live count of online vs offline resources

### F3 — Flood Simulation
- Animated water level rising over terrain
- Cells colored blue when submerged (elevation < water level)
- Resources below water level automatically go offline
- Water level slider: 0–15 meters
- Simulation speed control
- Reset to dry state

### F4 — Cyclone Simulation
- User places cyclone eye by clicking on map
- Three.js spiral particle animation around eye point
- Wind radius circle overlay (adjustable by severity slider)
- Resources within wind radius marked as damaged
- Optional: animate cyclone path across map

### F5 — Rerouting Engine
- When resource goes offline → automatically finds nearest alternative of same type
- Path drawn on map from offline resource to nearest available one
- Popup notification: "Shelter X offline → Rerouted to Shelter Y (2.3 km)"
- List of all active reroutes in sidebar

### F6 — Control Panel
- Region selector
- Disaster type toggle (Flood / Cyclone)
- Severity slider (1–10)
- Water level slider (flood only)
- Simulation speed
- Layer toggles
- Simulate / Reset buttons

### F7 — Stats Panel
- Total resources: N
- Currently offline: N
- Estimated affected population (based on capacity sum)
- Active reroutes: N
- Disaster type and severity label

## 6. Technical Requirements

### Frontend
- React 18 + Vite
- deck.gl for 3D map layers
- Three.js for cyclone particle system
- react-map-gl + MapLibre for base map
- Framer Motion for UI animations
- Dark theme, responsive layout

### Backend
- Python 3.11+
- FastAPI for REST API
- Pandas + GeoPandas for data processing
- NumPy + SciPy for distance calculations
- Synthetic JSON/CSV data (no real API dependency)
- SRTM elevation data (pre-fetched, served locally)

### Data
- Synthetic resource data (generated by Python script)
- SRTM elevation tiles (pre-downloaded for selected regions)
- OpenStreetMap tiles (CDN, no API key required for basic use)
