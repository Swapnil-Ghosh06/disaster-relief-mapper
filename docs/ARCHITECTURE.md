## Data Flow

### Flood Simulation Flow
```
User moves water level slider
        │
        ▼
React state: waterLevel = N
        │
        ▼
POST /flood/simulate { region, water_level_m: N, resource_ids }
        │
        ▼
flood_engine.py:
  for each resource:
    elevation = lookup(resource.lat, resource.lng)
    if elevation < water_level: mark OFFLINE
        │
        ▼
Response: { offline: [...], online: [...] }
        │
        ▼
React state: offlineIds updated
        │
        ├──▶ ResourceMarkers re-render (offline = grey/red X)
        │
        └──▶ POST /reroute { offline_ids }
                    │
                    ▼
             router.py: find nearest same-type online resource
                    │
                    ▼
             Response: { routes: [...] }
                    │
                    ▼
             RouteLayer renders paths on map
             InfoPanel updates route list
```

### Cyclone Simulation Flow
```
User clicks map to place cyclone eye
        │
        ▼
React state: cycloneEye = { lat, lng }
        │
        ▼
CycloneEffect renders Three.js spiral at that point
        │
        ▼
POST /cyclone/simulate { eye_lat, eye_lng, radius_km, severity }
        │
        ▼
cyclone_engine.py:
  for each resource:
    dist = haversine(resource.lat/lng, eye.lat/lng)
    if dist < radius_km: mark DAMAGED
        │
        ▼
Response: { damaged: [...], safe: [...] }
        │
        ▼
React state: offlineIds updated (damaged = offline)
        │
        └──▶ Same rerouting flow as flood
```

## Backend Module Responsibilities

```
backend/
│
├── main.py
│   └── FastAPI app, CORS config, route registration
│
├── engines/
│   ├── flood_engine.py
│   │   ├── load_elevation(region) → dict[lat,lng → elevation]
│   │   ├── get_submerged(water_level, resources, elevation_data) → list[id]
│   │   └── calculate_affected_capacity(offline_ids, resources) → int
│   │
│   ├── cyclone_engine.py
│   │   ├── haversine(lat1, lng1, lat2, lng2) → float (km)
│   │   ├── get_affected(eye_lat, eye_lng, radius_km, resources) → list[id]
│   │   └── apply_severity_damage(affected, severity) → list[id]
│   │
│   └── router.py
│       ├── find_nearest(offline_id, resource_type, online_resources) → Route
│       └── generate_routes(offline_ids, all_resources) → list[Route]
│
├── data/
│   ├── generate_data.py → writes resources.json
│   └── *.csv → elevation grids
│
└── models/
    └── schemas.py → Pydantic request/response models
```

## Key Design Decisions

| Decision | Choice | Reason |
|----------|--------|--------|
| Map engine | deck.gl + MapLibre | GPU-accelerated, open source, no paid key |
| 3D cyclone | Three.js overlay | Full control over particle physics |
| Backend framework | FastAPI | Auto-docs, fast, async-ready |
| Data storage | JSON/CSV files | Simple, no DB setup, portable |
| Elevation source | SRTM (pre-fetched) | Free, good resolution, no runtime API dependency |
| Rerouting algorithm | Haversine + sort | Simple, fast, sufficient for simulation scope |
| State management | React hooks | No Redux overhead for this scale |
| Styling | CSS variables + custom | Avoid heavy UI libraries, full control |
